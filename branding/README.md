# Branding

- `ix-logo.svg`: the IX company mark (teal bar, teal diagonal, navy diagonal) on a white tile. Use it for company branding: website, docs, store listings.
- `app-icon.svg`: the ixtable application icon: four building blocks with deep inner chamfers that open a diamond, in the same style. `node scripts/release/icons.mjs generate` renders it into `src-tauri/icons`.
- `mark-reference.png`: the original artwork the IX mark was redrawn from.

Both marks use teal `#0DB9B6` and navy `#10171D` on white. There is no dark variant.
